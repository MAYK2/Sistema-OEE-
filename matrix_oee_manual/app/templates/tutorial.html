Manual del Usuario: Paso a Paso

Sistema OEE Matrix
Bienvenido

Esta guía le mostrará cómo utilizar el sistema Matrix OEE desde la planificación hasta el análisis de datos. Siga los pasos a continuación para dominar el flujo de trabajo completo.

1

Carga de Orden de Trabajo (OT)

El proceso inicia con la definición de lo que se va a producir.

  • Cliente: Seleccione un cliente existente o registre uno nuevo al instante.
  • Planificación: Defina la fecha de inicio y la fecha estimada de entrega.
  • Productos: Agregue uno o varios ítems a la orden.

Figura 1: Formulario de creación de nueva Orden de Trabajo.

2

Acceso al Sistema (Login)

Para gestionar las órdenes y acceder a los tableros, es necesario identificarse.

El sistema cuenta con roles de usuario (Administrador, Supervisor, Operario) que determinan qué funciones están disponibles.

Figura 2: Pantalla de autenticación segura.

3

Configuración de Líneas

Antes de operar, asegúrese de que la configuración de turnos sea la correcta para un cálculo preciso del OEE.

Aquí puede definir los horarios de inicio y fin de turno para cada línea de producción (Ej. Embotellado, Sodas).

Figura 3: Panel de configuración de turnos por línea.

4

Monitorización y Dashboard

Supervise la producción en tiempo real.

El Dashboard principal le ofrece una visión inmediata del estado de la planta:

Disponibilidad

Medidor en tiempo real que compara el tiempo productivo vs. el tiempo total del turno.

Línea de Tiempo

Visualice las paradas y actividades minuto a minuto si hubiera actividad registrada.

Resumen de Producción

Contadores automáticos de producción diaria, semanal y mensual por producto.

Figura 4: Centro de comando y control de producción.

5

Historial y Detalles

Acceda al registro histórico de todas las órdenes finalizadas.

Desde esta lista puede auditar cualquier orden pasada, verificar tiempos, cantidades producidas y acceder al detalle minucioso de cada evento.

Figura 5: Registro histórico de producción.
